# Student Result System

A Java console-based application that manages student records and calculates academic results.

## Features

* Add student details
* Store marks for 5 subjects
* Calculate total marks
* Calculate average marks
* Generate grades (A, B, C, D, F)
* Search students by ID
* Display all student results

## Technologies Used

* Java
* ArrayList
* Object-Oriented Programming (OOP)
* Scanner Class

## Concepts Practiced

* Classes and Objects
* Constructors
* Methods
* Arrays
* Collections Framework (ArrayList)
* Searching
* Encapsulation Basics
